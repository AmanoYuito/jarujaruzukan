# 奴キャラ図鑑

ジャルジャルタワー／ジャルジャルアイランドに登場するキャラクターを探せる、非公式ファンサイトです。

- 公式画像・動画は再配布せず、公式YouTube動画へのリンクのみ掲載
- アカウント登録・広告・アクセス解析なし
- お気に入りは利用端末のブラウザ内だけに保存
- iPhoneの「ホーム画面に追加」に対応

本サイトはジャルジャル、吉本興業、YouTubeその他の権利者・関係者とは関係ありません。

## 毎日の自動更新

GitHub Actionsが毎日午前5時17分ごろ（日本時間）に、YouTube Data APIから両チャンネルの新着を確認します。

- アイランドは全動画を対象
- タワーは「ジャルジャルコント」「ネタのタネ」「本気ネタ（○億回記念を含む）」「煩悩ネタ」のみ対象
- 公式タイトル、公開日、サムネイル、YouTube説明欄を自動反映
- 登録済みのキャラ名・コンビ名が公式タイトルまたは説明欄にあれば自動で関連付け
- 未登録のコンビ名らしき語は `data/automation-candidates.json` に確認待ちとして保存し、公開情報として断定しない

リポジトリの Actions secrets に `YOUTUBE_API_KEY` を設定してください。APIキーはソース、公開サイト、実行ログへ直接書かないでください。
